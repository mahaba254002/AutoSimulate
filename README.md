# AutoSimulate — Alpha Research

A research-oriented quantitative experimentation platform for WorldQuant BRAIN, with a local browser workspace, documented data discovery, reusable expression templates, controlled alpha redevelopment and human validation.

The main application is in **[alpha-research-platform](alpha-research-platform/README.md)**.

Manual research and redevelopment work without a paid LLM API. Offline preview and unit tests do not require a BRAIN account. Remote catalogue discovery and simulations require the appropriate platform access.

The project demonstrates typed expression handling, indexed metadata storage, resumable downloads, failure-aware simulation scheduling, reproducible candidate generation and inspectable bandit feedback. It is a working local prototype; public source and tests are evidence of implementation, not a claim of guaranteed alpha performance or daily learning improvement.

The `ACE_API__Gold_ (1)` directory retains earlier ACE reference materials. The research platform's original workflow and engineering contributions are distinguished from these helpers in the documentation. Private credentials, account data, research outputs and environment files are excluded from the publication.
